# Claude Code Memory — Data-Science-For-Beginners

This file travels with the repo (OneDrive / git) so Claude Code has context on any machine.

## About this repo

Microsoft's open-source **10-week, 20-lesson Data Science for Beginners** curriculum.  
Owner/contributor: **Krzysztof** (Krzysztof Zaraza, DSV).

## Repo structure

```
1-Introduction/          # 4 lessons — what is data science, ethics
2-Working-With-Data/     # 4 lessons — relational/NoSQL/Python/pandas
3-Data-Visualization/    # 5 lessons — quantities, distributions, proportions, relationships
4-Data-Science-Lifecycle/# 3 lessons — acquisition, analysis, communication
5-Data-Science-In-Cloud/ # 3 lessons — Azure ML Studio, low-code
6-Data-Science-In-Wild/  # 1 lesson — real-world applications
data/                    # shared datasets (CSV, JSON)
examples/                # 5 beginner Python scripts (hello_world → real-world project)
sketchnotes/             # visual lesson summaries
translations/            # 50+ language translations of lessons
```

## Key file types

- **Jupyter Notebooks** — interactive lessons + assignments (solutions in `/solutions` subfolders)
- **Markdown** — lesson content and documentation
- **Python scripts** — `examples/` directory, progressively complex
- **Datasets** — birds, COVID-19, diabetes, mushrooms, taxi, honey, baseball, emails, Twitter JSON
